# 栖学 · 校园学习空间发现器

原生 HTML/CSS/JavaScript + 本机 Node.js 服务。无数据库、账号系统、付费模型或 API Key。

## 给队友：怎么打开

### Windows：日常只需双击

1. 下载项目并**完整解压**到本地文件夹（中文、空格路径均可），不要在压缩包里直接运行。
2. 首次准备：安装 [Node.js LTS](https://nodejs.org/)，需 Node.js 20 或以上、包含 npm。已经装好就跳过。
3. **双击 `start.cmd`**，会自动启动服务并打开浏览器。保留启动窗口，按 **Ctrl+C** 停止服务。

不需要先执行 `npm install`，不要直接打开 `index.html`。默认地址 `http://127.0.0.1:4173/`，端口被其他程序占用时自动换端口，以窗口显示的地址为准。重复双击会复用同目录、同版本已运行的服务，不停止其他程序。不同版本或不同项目副本不会混用。

### 第一次查询官方教室资源（可选准备）

**双击 `setup-official.cmd` → 输入 Y 确认安装 → 完成后重新打开网页。**

- 普通启动不会偷偷联网安装；此入口经确认后才下载本地 Playwright 组件，优先复用系统 Edge/Chrome，没有兼容浏览器时下载 Chromium。
- 新克隆/分发包**没有开发机的教室缓存或登录信息**。首次需在网页点“打开官方登录窗口”，在作品新开的官方窗口自行登录/完成二次认证，再进入教室查询并采集。其他普通浏览器的登录不会自动共享。
- 已有有效本周缓存时，查看推荐不必每次登录。无缓存/过期时会明确提示，不编造数据。
- 安装组件就绪不等于校园网络畅通、登录成功或数据已采集。

### Mac/Linux 或习惯终端

```sh
npm start
# 首次需要官方查询时运行，按提示确认：
npm run setup:official
```

自动打开浏览器失败时复制终端显示的地址。Linux 的浏览器还可能需要系统依赖；此处不自动修改系统。开发调试可用 `npm run start:server`（原始服务器，不自动开浏览器、不自动换端口），或 `node scripts/launch.mjs --no-open`。

更多排障见 `docs/START-HERE.md`。

## 0.8.0 标签界面与交互地图

- 主界面分为“找空间、校园地图、教室、图书馆、日程、数据连接”六个标签，按需展示；高级条件、设施资料和卡片依据折叠。
- 现有423间教室按官方名称归入21个楼宇组，六教默认只显示本楼12间，可继续加载；推荐也按楼宇切换，每批6间。
- 使用用户提供的校园地图内置10个示意标记，支持1–3倍缩放、楼宇定位，以及地图与教室列表双向跳转。六教可直接点选查看本楼教室。
- 地图上能辨认的文字附近才标记；其余楼宇位置待核实。坐标不是GPS、精确入口或步行导航，教室数量来自有效缓存。
- 本次精简界面验收可运行 `npm run test:ui`，用5组本地合成数据冒烟覆盖标签、分类、地图、推荐和手机宽度。地图边界见 `docs/CAMPUS-MAP.md`。

## 图书馆公开数据

直接双击 start.cmd 打开新版，图书馆区域自动读取清华官方公开座位页，**不需要登录，也不需要安装 Playwright**。教室官方认证方式不变。

- 图书馆和教室作为同级资源并列展示；一次提交学习需求，同时得到两类来源各自的条件候选，不把不同含义的数据混成分数。
- 图书馆按官网“今日剩余／总量”展示6个分馆，每卡有来源、详情、采集时间。剩余数字不是现场占用统计，也不保证到馆或整个学习时段有座。
- 页面可见时每60秒尝试更新；服务端共享缓存并合并并发，手动刷新最短间隔30秒。超过120秒、跨日或最近刷新失败时，仅作历史展示，不进入当前推荐。
- 图书馆只对包含此刻的今日学习窗口提供剩余条件推荐，不用当前数字预测未来。动态日程冲突同样阻止推荐；电源、讨论许可、安静程度、进入条件及开放时间仍待核实。
- 公开快照也存于忽略目录 data/private/，不进入分享包或Git；没有缓存的新机器首次打开即可匿名查询，不需要先查教室。

证据和数据口径见 `docs/LIBRARY.md`。

## 已实现与数据边界

- 四种学习场景、规则筛选、需求推荐、可交互卡片/详情及官方来源。
- 官方教室周课表只读采集、同周缓存、上海系统时钟、用户提供图片的6个节次钟点映射与自动匹配。
- 本机手动日程、临时事项、单次不参加和冲突检查；**个人官方学期课表导入暂缓**，并未实现。
- 教室“课表空闲”不等于允许自习、正在开放、设施可用或实时有座；未核实信息明确标注。课间/午休空档不自动认定空闲。
- `data/places.json` 当前无设施/许可均齐全的场所，完整场景卡片可能为0条；课表候选单独展示，不为凑数编造。
- 登录只在清华官方窗口进行，认证会话仅在内存中，停止服务后需重新登录；不接收、保存或上传账号密码。
- 本机缓存位于已忽略的 `data/private/`，不进入 Git 或分享包。图书馆已接通公开剩余数字；地图寻路、全时段座位预测和官方个人学期课表仍未接通。

## 目录

```text
start.cmd / setup-official.cmd  Windows 双击入口 / 可选查询组件安装
scripts/                       跨平台启动、自检和安装脚本
server.mjs                     仅监听 127.0.0.1 的本地服务
index.html / styles.css / js/   页面、交互、推荐与时间/日程规则
workspace.css / assets/         标签界面样式和用户提供校园地图
lib/                           官方只读连接与解析、运行环境检查
data/                          可公开的核实资料；private/ 不随代码分享
tests/                         单元、HTTP、启动与浏览器检查
docs/                          数据边界、排障、实施计划与验收记录
```

## 开发与测试

```sh
npm run check
npm test
npm run test:ui
```

浏览器测试需已有 Playwright/兼容浏览器，不是普通启动的前置条件。测试合成数据不会写入推荐资源。旧版长页面浏览器脚本保留作历史参考，0.8标签界面使用 `test:ui` 验收。实际执行情况见 `docs/TEST-RESULTS.md`，不把自动化模拟测试等同于真实账号/其他电脑的人工验收。
