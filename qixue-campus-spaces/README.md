# 栖学 · 校园学习空间发现器

### 0.5.1 连接修复与队友仓库

支持直连与清华 WebVPN 教室地址、iframe 和旧教务会话路径。门户与教室认证独立核验，已登录后持续检测；临时本地服务错误会重试，不直接认定官网退出。仅识别本作品打开的独立官方窗口，不共享普通浏览器登录。重启服务需要重新认证，不保存密码/Cookie。

本目录为共享仓库内的栖学应用，来源是本地稳定提交 `7ff2cdc`。同仓库的 `../thu-seat-live/` 保留队友的图书馆与地图项目，两者尚未整合。本目录不含原开发机的私有教室快照、个人日程或认证会话；新克隆后需要自行认证采集。不要把这些私有文件提交到 GitHub。

连接专项回归：`npm run test:connection-browser`（使用本机已有 Playwright 和 Edge，不下载依赖；合成官方页面，不代表真实账号已验收）。完整实际结果及5项人工验收见 `docs/TEST-RESULTS.md`。

原生 HTML / CSS / JavaScript 校园学习空间推荐网页。0.5版包含同周课表缓存、可见的课表条件推荐、上海系统时钟及本机手动日程/单次不参加与冲突检查。官方查询已实际取得423个教室。无数据库、付费模型或API Key。整学期/个人官方课表、节次钟点、路线、自习许可和图书馆仍未接通，实施路径见 `docs/SEMESTER-ROADMAP.md`。

## 数据边界

**已实际取得423个教室的官方课表记录，但自习许可和设施未齐。** `data/places.json` 暂时保持空列表，因此完整场景推荐仍为0条；课表候选单独展示，不能混为“已核实允许自习”。清洗后的本机课表快照位于已忽略的 `data/private/`，重启后标注历史与采集时间，不含凭据。

## 项目结构

```text
index.html              页面与无障碍基础结构
styles.css              桌面 / 手机响应式样式
js/app.js               数据加载、场景切换、卡片和详情交互
js/recommend.js         数据校验和仅依赖已核实事实的匹配规则
data/places.json         本地真实场所数据（目前待补充）
server.mjs              仅绑定 127.0.0.1 的本地静态服务器
tests/                  数据、规则、HTTP 和浏览器测试
docs/DATA.md            逐字段录入与官方来源要求
docs/ACCEPTANCE.md      人工验收清单
```

## 运行

安装 Node.js 后，在本目录（`qixue-campus-spaces`）执行：

```powershell
node server.mjs
```

浏览器打开 `http://127.0.0.1:4173`。按 Ctrl+C 停止服务器。

## 测试

```powershell
npm test
npm run check
```

已具备本地 Playwright 时可执行 `npm run test:browser`；其运行方式与实际执行结果见 `docs/TEST-RESULTS.md`。这不是应用运行所需的依赖。

注意：原版 `test:browser` 中的真实周缓存用例依赖原开发机的私有快照和对应日期，不属于新克隆环境的开箱即用测试。无需私有快照的连接专项使用 `npm run test:connection-browser`；报告中的合成官网页面不代表真实账号认证已经通过。

自动化测试中的合成数据仅验证规则，不代表真实场所，也不会被网页加载。人工验收和浏览器测试执行情况分别记录于 `docs/ACCEPTANCE.md` 与 `docs/TEST-RESULTS.md`。

## 首版范围

- 四种单选场景：安静学习、小组讨论、临时学习、需要供电。
- 只有明确核实为支持的场景才参与该场景推荐；未知不等于支持。
- 卡片显示位置、适用场景、官方公布时间、推荐依据与官方链接；支持详情对话框。
- 开放时间不能推导“正在开放”，也不推测实时座位或实时设施可用性。
- 未核实字段显示“待核实”，不拿 Wi-Fi、桌椅、图书馆类型等间接推断插座或安静程度。
- 官方连接由用户主动打开，在清华官方窗口完成登录及二次认证。作品不接收密码；本机临时会话不落盘。首次静态版本不会访问外部站点，0.2 版仅主动连接时启动官方窗口。
