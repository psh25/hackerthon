# 给第一次运行的队友

## 最短路径

Windows：完整解压 → 首次安装 Node.js LTS（20或以上，含npm）→ 双击 **start.cmd**。

如果拿到的是协作仓库，可直接双击**仓库根目录**的 start.cmd，会打开 `qixue-campus-spaces`，不必先 `cd`，也不启动或更改队友的图书馆应用。

初次需要教室数据，再双击 **setup-official.cmd**，输入 Y 确认下载。安装不要求管理员权限；受管机器的安装/网络策略可能仍需要向管理员确认。之后在作品自己打开的官方窗口认证和查询。不要把账号、验证码发给队友或填进命令行。

0.7.0起，**图书馆公开数字无需这一步，也无需登录**，打开页面即可获取。没有教室缓存不影响图书馆；没有网络时明确提示失败或历史，不制造空位数字。图书馆60秒共享缓存、超过120秒不用于当前推荐，不沿用教室周缓存。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示找不到 Node.js | 安装含 npm 的 Node.js LTS 后重新双击；启动窗口会保留提示。也支持自己将合法来源的便携 Node 放在应用目录 `runtime/node.exe`，安装查询组件时还需要对应 npm。分享包不自带 Node。 |
| 只看到文件/空白页，按钮不响应 | 不要双击 index.html；关闭该标签，双击 start.cmd 后使用 `http://127.0.0.1:端口/`。 |
| 文件夹在 ZIP 内 | 完整解压后再运行，保留 scripts/lib/js/data 等子目录，不单独复制入口文件。 |
| 浏览器没自动弹出 | 复制启动窗口显示的地址。系统需要有默认浏览器；不会擅自更改默认浏览器。 |
| 地址不是4173 | 原端口被其他服务/旧版/其他项目占用，启动器自动顺延；用显示地址，不要停止不认识的进程。手动日程/偏好按浏览器端口隔离，缓存文件仍属于各自项目。 |
| 重复双击 | 同目录同版本会复用已有服务；请保留最初启动的服务窗口。关闭网页不等于关闭服务。 |
| 提示需要查询组件 | 运行 setup-official.cmd，经你确认后才安装；不影响页面和已有缓存读取。若安装失败请保留窗口中的错误，检查联网后重试。 |
| 已在常用浏览器登录，作品仍未连接 | 作品只识别它自己打开的独立官方认证窗口。请在那个窗口登录/完成二次认证；不会读取常用浏览器的 Cookie。 |
| 新机器没有推荐 | 分享包不含校内私有缓存。请先完成官方查询；没有数据时不伪造推荐。查得空闲仍不代表有座或允许自习。 |
| 更新版本后还显示旧页面 | 停止自己原来的服务（Ctrl+C），重新双击新版 start.cmd，用新窗口地址；不要保留旧标签。 |
| 想换端口 | PowerShell：`$env:PORT=5000; npm start`。非法端口会给出错误，不会静默切换到错误地址。 |
| Mac/Linux | Node.js 准备好后在项目文件夹运行 npm start；需官网查询时再 npm run setup:official。Linux 浏览器系统依赖不自动安装。 |

## 5项人工验收

1. 队友首次完整解压，装好 Node 后双击 start.cmd，不输入命令即可打开首页，提交需求能得到结果或明确的无数据/未核实提示。
2. 同目录重复双击，打开相同地址，没有第二个服务窗口持续运行，已有认证窗口不被关闭。
3. 4173被其他程序占用时显示新的可用地址、自动打开该地址，原程序不受影响；关闭默认浏览器失败时有地址可复制。
4. 没有 Node/查询组件时，分别给出清楚的安装指引，窗口不闪退；取消安装不下载任何内容，普通启动仍能查看页面。
5. 全新副本不带开发者课表、登录会话或凭据；首次官方查询由使用者在官方窗口认证，采集后同周再打开可读缓存，未知信息不冒充实时有座。

其他电脑上的双击、网络下载、校园认证和默认浏览器关联需要现场验收；本机自动化用例不能替代这些检查。
