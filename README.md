# 校园学习空间协作仓库

本仓库目前保留两个独立应用，尚未合并成同一套前后端；互不覆盖代码或私有数据。

| 目录 | 功能 | 本机默认地址 |
| --- | --- | --- |
| `qixue-campus-spaces/` | 栖学：标签界面、楼宇分类与交互地图、教室周缓存、图书馆公开剩余、日程与官方连接 | `http://127.0.0.1:4173` |
| `thu-seat-live/` | 队友的图书馆座位看板及现有地图相关代码 | `http://127.0.0.1:8787` |

## 运行栖学：Windows 双击即可

1. 完整下载并解压仓库，不在 ZIP 内运行。
2. 首次安装 Node.js LTS（20或以上，包含npm），已安装则跳过。
3. **双击仓库根目录的 `start.cmd`**，自动打开网页。保留启动窗口；按 Ctrl+C 停止。

首次需要获取官方教室数据时，另双击根目录 **`setup-official.cmd`**，输入 Y 确认安装查询组件。普通启动不自动安装，不需要先执行 npm install。

重复启动复用同目录同版本服务；端口冲突会自动顺延，不停止其他程序。以启动窗口显示的地址为准，不要双击 index.html。

Mac/Linux 或习惯命令行：

```powershell
cd qixue-campus-spaces
npm start
```

连接官网由用户在作品打开的独立官方窗口自行认证，不接收密码，不保存 Cookie；普通浏览器的登录不自动共享。首次运行与排障见 `qixue-campus-spaces/docs/START-HERE.md`。根目录入口只启动栖学，不会自动启动图书馆看板。

0.7.0起，栖学内已集成**无需登录或Playwright的图书馆公开查询**，与教室同级展示并独立更新；此功能不要求启动另一个图书馆看板。图书馆60秒共享缓存、120秒后不用于推荐，不沿用教室周缓存；页面“今日剩余”不等于到馆有座。详细边界见 `qixue-campus-spaces/docs/LIBRARY.md`。

0.8.0把页面收为六个标签，教室按楼宇归类，并内置可缩放校园地图；点击六教等地图标记可进入本楼教室。原图来自用户提供文件，10个标记为文字附近示意坐标；未核实楼宇不猜测落点。精简验收运行 `npm run test:ui`，地图说明见 `qixue-campus-spaces/docs/CAMPUS-MAP.md`。

## 运行图书馆看板

```powershell
cd thu-seat-live
node server.js
```

各项目的依赖、数据口径和测试说明以各自 README 为准。两个项目可以使用不同端口同时运行。

## 同步与隐私

- 栖学代码来自本地稳定版本 `476bd89`（0.8.0），包含标签界面、楼宇分类、交互地图、双击启动与同级图书馆接入；不重写原项目提交历史，不更改队友原图书馆应用。
- **不上传**校内课表原始快照、学生个人课表、登录会话、账号密码、API Key、浏览器配置或本机未跟踪文件。
- 新克隆的栖学目录不含原开发机的423条教室缓存。首次使用需自行在官方窗口认证并采集；没有数据时不会编造推荐。
- 本次同步已包含楼宇示意地图，不表示个人学期课表、步行寻路与两个应用之间的数据整合已经完成。
- 个人官方学期课表导入暂缓，当前优先保证队友能顺利运行。
