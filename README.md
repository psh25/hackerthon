# 校园学习空间协作仓库

本仓库目前保留两个独立应用，尚未合并成同一套前后端；互不覆盖代码或私有数据。

| 目录 | 功能 | 本机默认地址 |
| --- | --- | --- |
| `qixue-campus-spaces/` | 栖学：教室周缓存、需求推荐、动态日程、官方连接与 WebVPN 识别 | `http://127.0.0.1:4173` |
| `thu-seat-live/` | 队友的图书馆座位看板及现有地图相关代码 | `http://127.0.0.1:8787` |

## 运行栖学

```powershell
cd qixue-campus-spaces
node server.mjs
```

静态页面和本地缓存服务无需安装依赖。连接官方窗口需本机已有 Playwright 与兼容浏览器，并由用户在官网自行完成认证；不保存密码或 Cookie。仅能识别作品自己打开的官方窗口，不共享普通浏览器登录。

## 运行图书馆看板

```powershell
cd thu-seat-live
node server.js
```

各项目的依赖、数据口径和测试说明以各自 README 为准。两个项目可以使用不同端口同时运行。

## 同步与隐私

- 栖学同步自本地稳定版本 `7ff2cdc`（0.5.1），另修复连接专项测试在新克隆时自动创建报告目录；采用新增子目录方式，不重写已有提交历史。
- **不上传**校内课表原始快照、学生个人课表、登录会话、账号密码、API Key、浏览器配置或本机未跟踪文件。
- 新克隆的栖学目录不含原开发机的423条教室缓存。首次使用需自行在官方窗口认证并采集；没有数据时不会编造推荐。
- 本次是代码同步，不表示个人学期课表、地图寻路与两个应用之间的数据整合已经完成。
